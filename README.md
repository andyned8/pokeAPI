# pokeAPI
-Descripción

Una página web donde puedes buscar cualquier Pokémon para ver su imagen, su altura, su peso y sus estadísticas de combate, además de explorar Pokémon por tipo y rotar una Pokébola en 3D con el mouse.

 -Objetivo

Mostrar en una sola página información detallada y actualizada de la base de datos oficial de Pokémon de forma rápida y visual.

-Actividades

Buscador interactivo: Escribes el nombre o número de un Pokémon (con sugerencias automáticas mientras escribes) y la página muestra instantáneamente su tarjeta con datos y estadísticas.

Filtro por categorías: Botones de tipos elementales que despliegan una lista de Pokémon correspondientes.

Visualizador 3D: Un modelo tridimensional interactivo de una Pokébola que el usuario puede girar libremente.

-Resultado esperado

Una herramienta web completa, fluida y funcional para consultar información de Pokémon.
